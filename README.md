# 🛡️ AEGIS PRO: Hybrid Ransomware Defense

## 📌 Overview
AEGIS PRO is a cybersecurity tool that detects ransomware using a two-layer approach:
1.  **Cloud Analysis:** Checks file hash against VirusTotal API.
2.  **Behavioral Analysis:** Detects rapid file encryption anomalies (Peeler's Algorithm).

## 🚀 Usage
1.  Install dependencies: `pip install -r requirements.txt`
2.  Add your API Key in `aegis_pro.py`.
3.  Run the defender: `python aegis_pro.py`.
